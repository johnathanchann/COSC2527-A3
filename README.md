
# Futball
Watch Messi AI vs T800 AI (inspired by terminator)

# Instruction

## Running the Game
- Go to arena scene
- Enable any parent object.

## Training agents
- Open NathanTrainingEnv/DanTrainingEnv/JohnathanTraining Env
- Run config file in /config

## Models location:
- \Assets\TFModels\Nathan: Nathan's models
- \Assets\TFModels\Johnathan: Johnathan's models
- \Assets\TFModels\Dan: Dan's models

Note:

* The starter project was created in Unity 6000.0.37f1.
